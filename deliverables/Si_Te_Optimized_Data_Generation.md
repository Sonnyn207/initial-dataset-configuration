## 参数与执行说明

来源：用户《数据集构建策略.pptx》第3页。沿用“已有构型 / 端点 + 生成手段 + 具体操作及产出”写法，保留120×6=720，不扩充类别。
执行要点：1. 晶相参考压力起点dc/BC8/R8=0 GPa、β-Sn=12 GPa、sh=20 GPa，需可靠原型CIF、相结构与稳定性确认；线性缩放不是体积缩放。体相随机扰动3个缩放取0.97/1/1.03，每个seed独立；5个剪切γxy=−4/−2/0/2/4%。
2. 缺陷母体在216原子dc中构建；Frenkel空位—间隙距离约4–8 Å，局域弛豫至max|F|<0.02 eV/Å。若弛豫复合，保存弛豫前的前驱态并重分类，不把已复合结构当缺陷。
3. 位错采用(111)面、b=a/2[1 −1 0]；螺型线方向[1 −1 0]，60°线方向[1 0 −1]。层错取u=a/12[1 1 −2]、a/6[1 1 −2]；孪晶取2和4双层厚度。表面≥12层、15 Å真空、固定底4层；Si(001)含2×1重构，小Si(111)胞不声称覆盖7×7重构。所有尺寸须检查镜像收敛。
4. SW只作候选生成：Δt=1fs；3500 K熔化20ps；淬火速率10^13/10^14 K/s，各5独立初速度种子，300 K平衡5ps后每轨迹取1帧。液态两Ti各NPT0bar平衡10ps后固定平均体积NVT10ps，每2ps取一帧；相关性未衰减则延长。
5. 固液界面216原子半固定半3500K加热15ps，解冻1700K；确认两相仍在后每≥2ps取5帧。含空位升温使用216原子删3个距离≥5 Å原子；100 K/ps升温至1600/1750/1900/2050/2200 K各保持2ps取1帧；按RDF/配位/扩散确认状态，未熔不强称液态。液态用低配位与自由体积描述，不套晶格空位。
6. NEB固定300K，端点力<0.02 eV/Å，路径F_perp<0.05 eV/Å；5图像不足则加到9或更多检验，再选5代表中间态。若Frenkel端点无可维持的母态，换用第二种可核实的缺陷迁移路径，并更新路径名称，几何预算不自动增加。
7. 同R的6个Te不跨结构分组；轨迹按母轨迹、路径按整条NEB分组。最高温度收敛空带，全部标签同一泛函 / 赝势；SW的E/F不能混入监督标签。720仅指最终静态标签，不含弛豫 / NEB / 收敛测试。
所有数值为待试算起点，未实际运行DFT。
