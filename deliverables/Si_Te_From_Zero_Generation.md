# 从零生成单晶硅初始构型：PPT补充说明

起点：用户无任何现成构型。附件脚本已运行并生成14个纯Si几何文件；未进行MD、DFT、缺陷核优化或势函数训练。计划的120个几何构型和720组标签尚未生成完成。

## 原型从哪里来

- 金刚石：ASE按晶格参数和diamond基元生成；不需要CIF或用户已有POSCAR。
- β-Sn、sh、BC8：按已知空间群、Wyckoff坐标和初始晶格参数生成；具体参数已写入脚本和PPT备注，参数只是几何起点，需在相应压力DFT优化。
- 为避免在没有核验R8坐标时依赖不存在的文件，首轮改为4个可直接生成的原型×5个缩放点=20。R8等放到拿到可靠晶体学坐标并验证之后扩展；不用其他化合物原型随意替换元素来冒充。

## 数据产生

| 任务 | 如何构建 | 具体做法 |
| --- | --- | --- |
| 晶相与扰动；40个 | ASE按晶格 / 空间群建晶；→ DFT弛豫 → 扰动 | dc：bulk(Si, diamond, a=5.43 Å)；β-Sn、sh、BC8分别按空间群141、191、206生成原型。4相弛豫后各取5个缩放点，得20个；dc再取15个独立随机扰动与5个剪切态，共40个。 |
| 点缺陷；20个 | 完美dc超胞；→ 删 / 插原子 → 局域弛豫 | 把8原子dc常规胞扩为3×3×3、共216原子；删1原子造空位，删最近邻2原子造双空位；把1原子替换为沿〈110〉的一对原子造分裂间隙，另配空位造Frenkel对。4类弛豫后各取5个扰动态，得20个。 |
| 位错 / 面缺陷 / 表面；15个 | 从dc取向晶格出发；→ 位移场 / 切层 / 镜像 / 切面 | Atomman在完整dc中插入螺型、60°位错偶极，弛豫后各取3个受载态，得6个；在(111)面切层平移造2个层错，镜像堆垛造2个孪晶；ASE切(001)/(111)面，再删 / 加表面Si，得5个。 |
| 非晶 / 液态 / 熔化；30个 | ASE完整晶格；→ SW-MD熔化 → 淬火 / 取帧 | 从64原子dc熔化起步，两条淬火速率各5种子得到10个非晶；Tᵢ=2000/3000 K各取5帧得到10个液态。216原子半区加热造界面取5帧；删3个原子后升温取5帧，共30个。 |
| 迁移路径；15个 | 先造缺陷初末态；→ IDPP插值 → NEB | 移动空位近邻Si生成跳跃终态；移动分裂间隙位置生成迁移终态；将间隙移回空位生成复合终态。端点弛豫后做固定Tₑ NEB，3条路径各选5个中间态，得15个；端点另归母结构。 |
| Tₑ标注；720组 | 上述120个R；→ 固定几何 → Mermin-DFT | 对120个几何构型逐一固定原子与晶胞，取Tₑ=300/3000/6000/9000/12000/15000 K，用Fermi–Dirac占据计算A、原子力和应力；120×6=720。SW仅造候选，不提供监督标签。 |

## 位错从哪里来

| 步骤 | 工具 / 输入 | 具体操作 |
| --- | --- | --- |
| ① 建完整晶格 | ASE生成dc-Si | bulk("Si", "diamond", a=5.43, cubic=True)得到8原子常规胞；输入Si弹性常数起点C₁₁/C₁₂/C₄₄=166/64/80 GPa，用于初始各向异性弹性位移场。 |
| ② 定义位错几何 | 给出滑移面、b和线方向 | 滑移面(111)，b=a/2[1 −1 0]；螺型线方向[1 −1 0]，60°线方向[1 0 −1]。这些向量用于构造取向晶胞，而非从小立方胞直接删几行原子。 |
| ③ 插入周期位错偶极 | Atomman Volterra / Stroh位移场 | Dislocation(ucell,C,[.5,−.5,0],ξ,[1,1,1],conventional_setting="f")，ξ取上述线方向；dipole(sizemults=(1,4,4),boxtilt=True,shiftindex=1)。已生成两类各384原子几何；一对相反b，净b=0。 |
| ④ 先优化缺陷核 | 先Si势预弛豫，再DFT核验 | 周期相容且净b=0仍不足以证明核心正确：检查最小距离，试不同滑移面层间偏移；先固定胞形优化原子，再核验尺寸收敛。用OVITO DXA / 位移差分图确认线方向、b及核。 |
| ⑤ 得到训练候选 | 两类弛豫核各取3个受载态 | 沿滑移方向分别施加−2/0/+2%剪切，保留6个有区别的几何；再进入六Tₑ单点。必要时后续扩充部分位错、不同滑移面间隙和位错环，不在首轮穷举。 |

## 实际核实范围

- 14个例子包括4个晶相原型、dc64与dc216、4个点缺陷母结构，以及2类位错各自的周期偶极与无位错参照。
- 螺型和60°偶极均384原子，Atomman保证构造的周期相容与相反b配对；构建后还需要独立结构分析和核优化，不能仅凭净b=0认定正确。
- 比较不同shiftindex后选择1；几何近邻检查并不替代力、能量、弹性边界与尺寸收敛。
- 层错：把沿[111]取向的完整Si切为上下两部分，沿面内〈112〉平移上半部分，起点u=a/12[11−2]与a/6[11−2]；检查原子重叠与周期镜像，再允许指定方向局域弛豫。
- 孪晶：从(111)完整堆垛出发，对指定晶面两侧使用镜像取向或将ABC改为镜像堆垛；取2与4个双层厚度的孪晶片，保证边界相容。检查Σ3取向关系及局部四面体配位，不能把任意镜像拼接直接称稳定孪晶。附件此次未生成孪晶文件。
- 表面：ASE surface() / diamond100() / diamond111()从完整晶格切面，设至少15 Å真空，固定底部4层；(001)人为加入二聚倾向后弛豫验证2×1重构；再删/加Si造表面缺陷。小(111)胞不声称捕获7×7重构。附件此次未生成表面、层错或孪晶文件。
- 本次未生成非晶、液态、界面或NEB轨迹；这些需要执行PPT和前版详细清单中的MD / DFT任务。
- 固定R六Te标签不能从几何文件直接得来；需用同一DFT赝势、泛函与收敛参数计算。最后单点PSTRESS=0，不继承母体优化外压。
- 所有相的“稳定性”必须结合压力、Te、离子温度与自由能验证。几何原型文件和最小距离检查不证明相稳定或核正确。
